## [Descrição]; 
O SBN (Symbol-Based Notation) é um sistema educacional de codificação e decodificação de mensagens desenvolvido para demonstrar o funcionamento de criptografias clássicas e, acima de tudo, expor suas fragilidades estruturais frente a ataques de segurança modernos.

## O que o projeto busca resolver?
A segurança por obscuridade ou o uso de cifras fracas criam uma falsa sensação de proteção. O principal objetivo deste programa é *conscientizar o usuário sobre quão vulneráveis as cifras clássicas são*. 

Ao demonstrar que um computador consegue quebrar uma mensagem criptografada pela Cifra de César em frações de segundo através de força bruta, o projeto serve como um alerta prático para a importância da evolução dos algoritmos criptográficos modernos (como o AES).
